# Ishtiyaq Alam Portfolio

This version keeps all information from the original portfolio and adds:

- A downloadable CV PDF
- A Live Projects section
- A detailed contact panel
- Responsive visual improvements while preserving the original dark purple/blue theme

## Open locally

Open `index.html` in a browser.

## Add another project

Open `script.js` and find the `projects` list near the top. Copy the existing project object and change these values:

```js
{
  title: "Project Name",
  category: "Project Type",
  description: "Short project description",
  technologies: ["HTML", "CSS", "JavaScript"],
  liveUrl: "https://your-live-link.com",
  sourceUrl: "https://github.com/username/repository"
}
```

`sourceUrl` may be left empty when source code is not public.
